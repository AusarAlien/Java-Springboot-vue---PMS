# 论文撰写要点

## 1. 项目背景与行业痛点（200–300字）
医药零售与医院药房在“多品种、小批量、短保质期”的经营特征下，库存周转与合规追溯压力显著。传统手工台账和分散式系统常导致入库出库不一致、批号与效期难追踪、盘点成本高、缺货与积压并存等问题。随着监管对药品流向、处方合规与冷链管理要求提升，药店管理需要实现从采购、入库、调拨到销售的全流程数字化与权限审计。同时，疫情后线上线下一体化经营加速，门店希望通过数据化报表提升补货决策与运营效率。基于此，构建一套覆盖药库、药房、物资、挂号与权限的综合管理系统，可降低差错率、提升可追溯性与管理透明度。

## 2. 近年文献现状综述（3–5篇）
近年研究强调药品流通的合规与可追溯性，行业报告指出药品流通企业正在加快信息化改造与精细化库存管理，以降低周转天数并提升供应保障能力[1][2]。在技术实现方面，医院与药房管理系统研究普遍采用B/S架构、角色权限控制与数据统计模块，以支持批号/效期追踪与出入库自动化[3]。此外，医疗信息化的发展趋势强调与监管标准衔接，以及数据驱动的业务决策支持，这为药店管理系统的统计分析与预警功能提供了现实依据[4][5]。

## 3. 系统功能、创新点与论文结构
**系统功能**
- 登录与权限控制：用户/角色/权限管理、登录日志审计。
- 药库管理：药品入库、出库、库存、批号与效期管理。
- 药房管理：门店药品管理与调拨。
- 物资管理：耗材与辅助物资管理。
- 挂号管理：客户挂号信息管理。
- 统计查询：库存、销售与出入库统计。
- 药品类型/客人类型管理：基础数据维护。

**创新点**
- 以全流程闭环管理为核心，实现“药库-药房-统计”一体化。
- 细粒度权限+日志审计，满足合规要求并提升可追溯性。
- 统计报表与查询模块支撑补货决策与运营优化。

**论文结构安排**
1. 绪论：研究背景、意义、国内外现状与研究内容。
2. 相关技术：Spring Boot、Vue、MyBatis-Plus、Spring Security等。
3. 需求分析：业务流程、功能需求、非功能需求。
4. 系统设计：总体架构、数据库设计、模块设计与权限模型。
5. 系统实现：关键模块实现与核心代码说明。
6. 测试与结果：功能测试、性能与安全性验证。
7. 总结与展望：成果总结与未来优化方向。
